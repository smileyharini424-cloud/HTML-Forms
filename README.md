# HTML Forms

## Explanation

This program demonstrates how to create a basic form in HTML.

The form collects information such as name email password gender course and message.

## Problem Statement

Create an HTML webpage containing a form with different input fields and controls.

## Features

- Creates a basic HTML form
- Accepts text input
- Accepts email input
- Accepts password input
- Provides radio buttons
- Provides a dropdown list
- Provides a textarea
- Includes submit and reset buttons

## How It Works

The <form> tag creates the form.

The <label> tag provides a description for each input.

The <input> tag creates different types of input fields.

The <select> tag creates a dropdown list.

The <option> tag provides choices in the dropdown.

The <textarea> tag creates a multi-line text field.

The submit button submits the form.

The reset button clears the entered values.
